# Decision log archive

These are dated decision and audit logs: project history, not user documentation. Nothing in the user guides depends
on them, and they are never updated after the fact. The IDs inside them are local to the audit that minted them:
`F<n>` is a finding number in that round's register (or the campaign's findings file) under [`docs/audits/`](../audits/README.md) (for example F14 in
round 2, F22 and F23 in round 3), and `K<n>:P<n>` names a live-prompt campaign cell (install combination `K<n>`,
probe type `P<n>`; see [`docs/audits/README.md`](../audits/README.md)). The same F-number can recur across rounds, so
read it together with the file's date.

This directory holds point-in-time session retrospectives — findings and rationale for a specific
audit or migration, as opposed to `docs/reference/` and `docs/guides/`, which describe the system as
it stands today. A decision log is kept here only while its rationale is still load-bearing (code or
docs elsewhere cite it); once superseded, it is deleted and summarized below instead, so the pointer
survives even though the file does not — full text is always recoverable from git history via the
commit hash listed.
