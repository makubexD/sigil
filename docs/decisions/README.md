# Decision log archive

This directory holds point-in-time session retrospectives — findings and rationale for a specific
audit or migration, as opposed to `docs/reference/` and `docs/guides/`, which describe the system as
it stands today. A decision log is kept here only while its rationale is still load-bearing (code or
docs elsewhere cite it); once superseded, it is deleted and summarized below instead, so the pointer
survives even though the file does not — full text is always recoverable from git history via the
commit hash listed.
