# `shared/feature` — porting the /feature conductor into the catalog (2026-09-30)

`shared/feature` (`catalog/shared/skills/feature/`) is the gated spec-driven-development conductor
that was previously a hand-installed Claude Code user skill (`~/.claude/skills/feature`). It
conducts [addyosmani/agent-skills](https://github.com/addyosmani/agent-skills); it does not bundle
or replace it. It ships alone in the `spec-driven` pack (`packs.yaml`).

## Decisions

| Decision                                                                                                                                                                     | Why                                                                                                                                                                                                                                                                                                                                                                                     |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Both Claude and Copilot** (no `platforms:`).                                                                                                                               | agent-skills installs on both — Claude Code as the `agent-skills@addy-agent-skills` plugin, Copilot CLI via `copilot plugin install`, VS Code and other agents via `npx skills add addyosmani/agent-skills` (its README and `docs/copilot-setup.md`, read 2026-09-30). Restricting to Claude would have kept only the source's accidental coupling.                                     |
| **agent-skills skills and agents are named by bare name** in the body; the `agent-skills:<name>` form is stated once as the Claude Code spelling.                            | The `agent-skills:` prefix is a Claude Code plugin namespace; agent-skills' own Copilot guide says it "means nothing to Copilot", where skills resolve by their frontmatter `name`. No lexicon term was added: `LEXICON_TERMS` holds whole-value substitutions, and a namespace _prefix_ would stretch it into general templating, which `src/targets/lexicon.ts` explicitly rules out. |
| **`$ARGUMENTS` → `{sigil:arguments}`, `CLAUDE.md` → `{sigil:conventions-file}`.**                                                                                            | The provider-neutral body lexicon (`provider-neutral-body-lexicon-2026-08.md`); `provider-term-leak` fails `sync --check` otherwise.                                                                                                                                                                                                                                                    |
| **`disableModelInvocation: true` stays, plus a `whenToUse`.**                                                                                                                | Claude emits `disable-model-invocation`, so `/feature` runs only when typed. Copilot has no equivalent field and drops it; there the skill is model-dispatchable, so `whenToUse` (rendered as "## When to Use") states the explicit-request trigger and the not-for cases (bug, typo, review).                                                                                          |
| **Claude-only mode guidance moved to `references/examples.md`**, as a Claude Code / VS Code Copilot mode map; the body keeps a neutral "0-3 read-only, 4-6 need edits" rule. | Lean SKILL.md + on-demand references (`distribution-channels-2026-09.md`); the body stays correct on both tools.                                                                                                                                                                                                                                                                        |
| **Examples genericized** (`mytool` instead of the author's `gid` project).                                                                                                   | Catalog artifacts ship to every consumer; project-specific prompts would confuse them. A test guards it.                                                                                                                                                                                                                                                                                |
| **Own `spec-driven` pack, not `essentials`.**                                                                                                                                | It needs a separately installed dependency; putting it in `essentials` would cost every user its description tokens (always-on) whether or not they have agent-skills.                                                                                                                                                                                                                  |
| **User-level `~/.claude/skills/feature` left in place.**                                                                                                                     | Out of scope; replacing it via `sigil add` is the user's call.                                                                                                                                                                                                                                                                                                                          |

The body is 117 lines, over the advisory `body-density` target (~90), like `shared/cli`/`shared/wizard`.
It is only loaded on invocation (user-invoked on Claude), so it was kept whole rather than splitting the
phase contract across files.
